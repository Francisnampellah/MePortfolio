# Homepage fonts

## Satoshi-Variable.woff2

- **Foundry:** Indian Type Foundry / Fontshare
- **Source:** https://www.fontshare.com/fonts/satoshi
- **License:** ITF Free Font License — free for personal and commercial use,
  including webfont embedding.
- **Axes:** weight 300–900, upright only (no italic file is loaded; the site
  does not use italics).

Stands in for **Aeonik** (CoType Foundry), the sans used on lusion.co. Aeonik is
a paid licence and is deliberately not vendored here. If a licence is acquired,
drop `Aeonik-Regular/Medium/RegularItalic.woff2` into this directory and point
`localFont` in `src/app/page.tsx` at them.

The companion mono, **IBM Plex Mono**, is the exact face lusion.co uses. It is
OFL-licensed and pulled through `next/font/google`, so it is not vendored.
